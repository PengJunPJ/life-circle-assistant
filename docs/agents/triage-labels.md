# 分流标签

各项工程技能使用五种标准分流角色。本文件将这些角色映射到本项目问题追踪系统实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本项目使用的标签 | 含义 |
| -------------------------- | ---------------- | ---- |
| `needs-triage`             | `needs-triage`   | 等待维护者评估该问题 |
| `needs-info`               | `needs-info`     | 等待需求提出者补充信息 |
| `ready-for-agent`          | `ready-for-agent`| 需求描述完整，可以交给代理处理 |
| `ready-for-human`          | `ready-for-human`| 需要人工实施或判断 |
| `wontfix`                  | `wontfix`        | 不再处理该问题 |

当技能提到某个角色时，例如“应用 AFK-ready 分流标签”，使用本表中对应的实际标签字符串。

如果项目后续采用其他标签命名，可修改“本项目使用的标签”一列。
