# 真实社区对比测试报告

编写日期：2026-10-12。项目：15分钟生活圈智能体检与规划助手。

本报告使用仓库已有的真实百度地图测算归档，主案例为广州市黄埔区沙涌长盛花园，对照为红山街道海韵东路。归档证据支持“路网预测与直线估算”“冷/热缓存性能”“同源网格复核”三类对比。**目前没有现场实走记录；实际步行时间、居民感受和独立来源准确率尚未验证。** 本次没有重新调用地图 API，也没有把模拟数据作为真实社区证据。

## 3. 路网预测与直线估算对比

### 3.1 方法

对各社区中心和设施坐标使用当前代码的局部平面距离近似：

```text
dx = 经度差 × 111320 × cos(平均纬度)
dy = 纬度差 × 111320
直线距离 = sqrt(dx² + dy²)
直线估算分钟 = 直线距离 / 75
绕行系数 = 路网步行距离 / 直线距离
```

75 m/min（4.5 km/h）是本报告明确设定的直线估算基线，不是现场测得的步速。路网预测时间直接取归档报告，未用上述速度反算；时间已由原报告保留到 0.1 分钟。直线距离四舍五入为米，估算时间和绕行系数用未取整距离计算。

### 3.2 沙涌长盛花园（2026-10-12）

| 目标设施 | 直线距离 m | 直线估算 min | 路网距离 m | 路网预测 min | 绕行系数 | 15 分钟判断 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 沙步农贸批发市场 | 520 | 6.93 | 866 | 12.3 | 1.67 | 两者均判定可达 |
| 广州市黄埔区新港小学(西校区) | 694 | 9.25 | 1,447 | 20.6 | 2.09 | 直线估算可达，路网预测不可达 |
| 领好超市(沙步店) | 335 | 4.47 | 739 | 10.5 | 2.20 | 两者均可达，但直线明显低估时间 |

小学示例是核心发现：坐标直线距离不足 700 m，实际路网模型却返回超过 1.4 km 的路线，15 分钟判断翻转。应在现场重点核查起终点入口与绕行原因；当前没有证据认定具体围墙、封闭入口或过街设施导致了这次绕行。

红山三个例子说明，直接用 1 km 圆覆盖会忽略路网通达性。它们不是该类别的最快可达设施：中心到小学的最快归档时间为 12.2 分钟，到药店为 14.7 分钟，到医疗为 13.2 分钟。因此“某个指定设施超时”不等于“该类别全部不可达”；网格分类必须比较全部候选中的最快成功路线。

## 5. 冷/热缓存真实性能对比

测试为相同中心、15 分钟分析模式、七类设施；先用空步行缓存运行，再复用缓存运行。未使用种子。性能归档记录单次冷测与单次热测，未进行多次重复，不提供统计置信区间或 SLA 承诺。

| 指标 | 冷测 | 热测 |
| --- | ---: | ---: |
| 应用报告耗时 | 149,156 ms | 13,218 ms |
| 外部测量总耗时 | 149,272 ms | 13,260 ms |
| 应用地图调用计数 | 263 | 18 |
| 其中设施调用计数 | 18 | 18 |
| 其中步行调用计数 | 245 | 0 |
| 步行缓存命中/未命中 | 0/1,291 | 1,291/0 |
| 步行包装器提供方调用 | 108 | 0 |
| 最终步行失败/降级结果 | 0/0 | 0/0 |
| 报告完整性 | complete | complete |

按应用报告耗时计算，冷测耗时是热测的约 **11.28 倍**，热测减少 **135,938 ms（91.14%）**；应用调用计数减少 **245（93.16%）**。外部总耗时是另一计时口径，未混用于上述比例。包装器调用、内部拆分接口调用、坐标对和 HTTP 尝试次数不同，263 不能作为百度实际计费账单。

冷测步行包装器记录 7 次超时和 7 次重试，最终失败为 0。因此“完成”表示最终取得有效结果，不表示全过程没有超时。

去除设施/网格的 `source` 和 `calculation_method` 两类缓存来源字段后，逐项核对冷/热 `summary`、`isochrone`、`scoring`、`category_scores`、`facilities`、`facility_normalization`、`service_areas` 与 `recommendations`，业务内容一致。热测沿用缓存，不应称为独立第二次路网现场验证。

## 6. 地图路线展示证据及现场实走待办

仓库有[真实地图与 AI 截图](../life-circle-assistant/docs/contest/submission/screenshots-20261015/README.md)、[真实模式操作录像](../life-circle-assistant/docs/contest/submission/v2.3.0-real-demo-20261012.webm)和[路线捕获 JSON](../life-circle-assistant/docs/contest/submission/real-demo-evidence-20261012.json)。捕获 JSON 中，从沙涌中心到 BD-09 `(113.533499,23.093152)` 的路线为 747 m、679 秒，含折线与步骤。这能佐证地图路线展示使用真实返回结果，但录像是在应用内操作，不能称为现场步行视频。

路线展示接口与矩阵分析接口可能选取不同路线或时长；复核时须同时记录接口、起终点、采样时间及入口，不能用不同端点或不同接口结果直接计算预测误差。

### 6.1 现场验证方案（未执行）

使用[实地步行核验记录模板](实地步行核验记录模板.md)采集第 3 节六条代表路线；再补充 15 分钟阈值附近的网格与正常/稀疏/重点盲区的分层样本。建议两位观察者、每条路线至少两次，并在事前固定采样规则；这是补充方案，不是已经完成的测试或赛事规定。

现场必须记录社区实际出入口、设施可用入口、开始/结束时间戳、到达条件、轨迹坐标系、红灯等待、个人停留、道路封闭和设施开放状态。应先选择合法可行的步行路线，避免为了复现算法路径穿越封闭或危险路段。只走到校门或诊所入口不能证明可入学、可预约或已获得服务。

“绕路明显”“遮阴不足”“过街等待久”“老人通行困难”等步行感受需要观察者当场记录，并与客观计时分列。当前这些感受字段全部待填写，本文没有居民满意度或体验结论。

### 6.2 现场完成后统计

对同起终点、对应采样时刻的预测 `p_i` 和包含过街等待但排除个人非通行停留的实走 `a_i`，计算平均偏差 `mean(p_i-a_i)`、MAE `mean(|p_i-a_i|)`、MAPE `mean(|p_i-a_i|/a_i)×100%`（剔除无效/零实走值），并报告 `(p_i≤15)` 与 `(a_i≤15)` 的一致率和混淆矩阵。未到达或入口不可用须单列不可通行，不能随意填零或一个大时间。

目前现场有效配对数为 **0**，上述指标均为 **未测**。直线基线和路网模型可在同一现场样本集分别计算误差，届时才可判断哪个更接近实际。

## 7. 结论、限制与仍需补充的内容

现有证据支持路网计算比直线圆覆盖表达出更强的绕行差异，且缓存能在这两次相同请求中保留业务结果并降低耗时。核心设施网格与历史同源标注具有较高一致性，但这不构成独立现场准确率。

| 待补充事项 | 状态 | 所需材料 |
| --- | --- | --- |
| 社区实走及真实步行感受 | 未完成，需现场人员 | 计时、轨迹、入口照片、观察记录 |
| 多源设施独立配对验证 | 未完成，需数据与人工标注 | 合法可保存样本、配对真值、错误案例 |
| 红山全网格人工基准 | draft，未完成 | 64 格核查及独立证据 |
| 公园等类别语义误命中纠正 | 已发现，尚未修正 | 公众开放属性、设施类别标注及规则改进 |
| 采样等时圈边界误差 | 未现场验证 | 阈值附近实走、外扩/孔洞处理对照 |

地图检索只取关键词第一页，设施类别误命中、入口吸附、缓存时效、网格中心代表性以及等时圈 1,250 m 上限均可能影响结论。算法细节与优化设计见[技术设计文档](技术设计文档.md)。
