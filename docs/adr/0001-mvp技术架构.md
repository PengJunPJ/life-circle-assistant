# MVP 技术架构

项目第一阶段采用 Vue + TypeScript + Vite 构建 Web 前端，采用 FastAPI 构建后端服务，使用 SQLite 保存样例数据和分析缓存，并通过 Docker Compose 提供可复现的运行环境。选择前后端分离方案，是为了同时满足地图交互、百度地图 API 调用、空间分析和比赛评审部署的需要；SQLite 和 Docker Compose 则控制 MVP 的部署复杂度，后续可以替换为 PostgreSQL 等生产组件。

## 备选方案

曾考虑 React 或单体 Nuxt/Next.js 方案，最终选择 Vue + FastAPI，以便保持前端交互与 Python 空间计算的边界清晰。
