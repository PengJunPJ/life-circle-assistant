# 比赛 MVP 范围与样例地区

第一阶段聚焦比赛可演示的单城市单样例闭环，样例地区确定为广东省广州市黄埔区。系统首先支持地址定位、15 分钟步行等时圈、重点民生设施检索与统计、服务盲区识别、综合评分、体检报告和规划建议，不在 MVP 阶段扩展多城市管理、用户体系或城市级长期运营能力。这样可以优先覆盖赛事要求的功能正确性、地图 API 调用、可视化和开源部署评分点。

## 当前默认规则

- 步行时间阈值为 900 秒。
- 分析范围为分析中心点周围 1 公里。
- 重点设施包括菜市场、药店、小学、医疗服务、养老服务和便利店。
- 服务盲区以网格点到最近同类设施的步行可达性和设施存在性综合判断。
