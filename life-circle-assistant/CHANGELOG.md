# 更新日志

本项目使用语义化版本号记录可交付版本。当前赛事交付版本为 `2.2.0`。

## 2.2.0（2026-10-08）

### 新增

- 增加可选的大模型报告解读，支持超时、并发和重试控制，并对输出证据引用进行校验；未配置模型时使用规则模板降级。
- 增加广州市黄埔区沙涌长盛花园真实社区报告和 64 条网格/类别核查记录。
- 历史报告支持触底分页加载与地址模糊搜索。

### 改进

- 优化服务区域图层交互和地图选择状态。
- 修复社区核查脚本 Ruff lint 与格式检查问题。

### 验证

- 后端测试：112 项通过。
- 前端测试：44 项通过；lint、类型检查与生产构建通过。
- Ruff lint 与格式检查通过。

### 数据可信度边界

- 沙涌长盛花园基准 64/64 已完成，但核查与预测同用百度地图数据及分类规则，只能说明同源一致性，不代表跨来源准确率或整体泛化能力。
- 独立来源、多社区准确性验证仍待补充；真实测算的 API 调用、超时和重试情况见归档报告。

## 2.1.1（2026-09-28）

### 新增

- 步行测算接入百度批量算路 `/routematrix/v2/walking`，按点对上限 100 分块取回矩阵；分块失败自动退化逐对 directionlite，单坐标对保留 steps 折线。
- 等时圈首环 24/16 个方向采样合并为一次批量步行请求。
- 设施覆盖评分下方新增类别得分雷达图，悬浮展示各类别得分明细。
- 步行缓存种子与启动导入：缓存为空时导入默认中心真实测算快照并重盖 TTL，干净环境首跑由约 124 秒降至约 19 秒；`/api/health` 新增 `seeded_walking_cache` 字段，`LIFE_CIRCLE_SEED_WALKING_CACHE=0` 可关闭。
- 性能基线补充 2.1.0 七类口径真实复测：冷缓存 124 秒 / 200 次调用，全缓存 12.5 秒 / 18 次调用。

### 变更

- 步行 API 调用量改以客户端真实 HTTP 计数披露，避免批量分块少计调用次数。

### 已知限制

- 缓存种子为 2026-09-28 的历史真实测算快照，导入时按启动时刻重盖 TTL；需要最新测算时清空 `walking_cache` 并关闭种子开关。

## 2.1.0（2026-09-27）

### 新增

- 民生设施扩充至 7 类：新增养老、公园绿地、便利超市，含百度逐词检索关键词、离线快照种子、地图图例与图层开关。
- 设施覆盖评分柱状图悬浮提示，展示类别得分、设施数量、最近步行时间、综合权重与三个子项得分；数据无效类别附原因说明。
- 深浅主题切换改为 View Transitions 羽化软边扩散过渡（420ms ease-out），从点击处晕染展开；不支持的浏览器或偏好减少动效时降级为颜色 crossfade。

### 变更

- 类别权重再平衡至合计 100：菜市场 18、药店 18、小学 18、医疗服务 16、养老 10、公园绿地 10、便利超市 10。
- 扩展类别（养老、公园绿地、便利超市）不参与 16 格服务盲区网格测算，仅计算覆盖度与最近可达；赛题盲区硬指标仍为核心四类。该取舍同步更新至 ADR006。
- 性能基线文档补充口径说明：既有基线数据采集于 4 类别配置，7 类别复测完成前不作为当前口径结论。

### 已知限制

- 扩展类别暂无独立服务区域网格与盲区结论，规划建议仍聚焦核心四类盲区。
- 真实模式下核心四类网格在冷缓存时耗时较长（受百度 QPS 限流约束），缓存命中后显著加快。

## 2.0.0（2026-09-21）

### 新增

- 可替换的地图提供方边界，以及本地快照和百度地图双模式。
- 按设施类别计算的步行服务区域、重点盲区和设施稀疏区。
- 可解释的类别评分、综合评分、规划建议和新增设施改善模拟。
- SQLite 任务、报告和步行缓存持久化，支持历史报告、重新运行和报告比较。
- JSON、CSV、GeoJSON 和 PDF 报告导出。
- 移动端工作台、键盘可达性和数据质量说明。
- 后端、前端和容器冒烟的统一质量检查入口。

### 修复

- 修正零设施和部分失败场景下的评分语义。
- 统一地址、坐标、地图标记和报告中的分析中心点。
- 将多关键词设施检索拆分为逐词请求并去重，避免组合查询造成召回缺失。
- 修正 Docker Web 健康检查对 IPv6 `localhost` 的误判，明确使用 IPv4 回环地址。

### 已知限制

- 当前内置快照是可复现的合成离线样例，不代表最新真实 POI。
- 真实社区对比仅覆盖单中心、单日和单地图提供方，不能外推为整体准确率。
- 系统尚未纳入口径统一的人口、设施容量、开放时间、招生边界和现场可进入性数据。
- 当前版本适合作为赛事功能型 Beta 和规划辅助演示，不应直接作为正式规划审批依据。
