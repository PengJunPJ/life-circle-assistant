## 复现

在已配置真实百度服务和模型服务、并启动本机前后端后运行：

```sh
node life-circle-assistant/scripts/capture_introduction_real.mjs
node life-circle-assistant/scripts/refine_introduction_captures.mjs
```

第二步连接第一步保留的采集浏览器，会通过原生图层开关调整展示并重新调用一次模型摘要。运行会产生真实地图和模型服务调用。
