# 限制与披露汇总

评审可据此判断哪些结论可直接使用、哪些只能作为演示。本页与报告内披露、发布说明保持一致；如有冲突以报告内字段为准。

## 数据可信度

- **离线快照为合成样例**：`backend/data/baidu_snapshot.json` 用于无凭证演示与 CI，其设施、地址与分数不代表任何真实社区；界面与报告保留"非实时数据"提示。
- **缓存种子为历史真实测算快照**：`backend/data/walking_cache_seed.json` 采集于 2026-09-28，启动时仅当缓存为空导入并按启动时刻重盖 TTL；命中种子会在报告缓存指标与 `walking_cache_used` 质量事件中披露。需要最新测算时清空 `walking_cache` 并设 `LIFE_CIRCLE_SEED_WALKING_CACHE=0`。
- **真实报告可能混合缓存与降级估算**：报告 `data_quality` 区披露缓存命中、限流/超时/重试、部分失败与降级估算；混合来源的结论应降低表述强度。

## 准确性边界

- **跨来源盲区识别准确率尚未验证**：沙涌长盛花园 64/64 标签已完成，但核查和预测使用同一百度地图数据源与相近分类规则，只能作为同源一致性证据；不能据此宣称跨来源准确率或普遍泛化成绩。
- **当前 POI 主分析仍为百度单源**：高德观察适配器和报告辅助摘要已实现，但默认关闭；书面许可、真实双源 fixture 与 50–100 对人工标签尚未完成。现有评分、覆盖及盲区结论均非多源结果。
- **单社区不外推**：现有真实核查仅覆盖广州市黄埔区一个中心点；不同路网密度、设施分布的社区需重新核查。
- **历史语义错配材料仅作限制记录**：早期萝岗/红山地址与设施错配的材料保留为修复记录，不作为成绩证明。

## 能力边界

- **外部坐标转换依赖真实服务**：WGS84/GCJ-02 → BD-09 调用百度 Geoconv V2；离线快照只允许已是 BD-09 的坐标原样通过，不提供近似或伪造转换。
- **扩展三类不产盲区结论**：养老、公园绿地、便利超市只计算覆盖度与最近可达，不生成服务区域网格；规划建议只引用核心四类盲区。
- **等时圈为近似连通区域**：基于扇形采样与二分细化推导，未获取底层路网拓扑；采样不足时降级为演示边界并显式标记。
- **AI 解读是增强层不是事实源**：只解释报告已有实体，拒绝或降级未知设施/网格/分数；模型错误不破坏原始报告。
- **非生产系统**：不含账号权限、监控、备份与多租户能力；不作为规划审批依据。

## 工程与配额边界

- 真实模式受百度 QPS 配额约束（默认全局 1.5 QPS）；冷缓存耗时与配额直接相关，性能数字须注明档位与配置。
- 健康检查只报告真实模式是否完成配置，不主动消耗百度配额；显式 `POST /api/map/probe` 只验证地理编码端点，不能代表 POI、步行接口或浏览器底图权限全部可用。
- CI 不运行真实 API 测试；真实测算只在人工或受控集成流程执行，避免配额与网络波动造成误报。
- Gitee Go 门禁与 master 保护分支**尚未实跑绑定**：当前质量门禁为 GitHub Actions 与本地 `make quality`，不能表述为 Gitee 上已生效的强制门禁（见 [../research/gitee-go-quality-gate.md](../research/gitee-go-quality-gate.md)）。
- 依赖合规材料记录的是 requirements、package-lock、Dockerfile 和 GitHub Actions 的工程审计口径；漏洞扫描、SBOM 和许可证清单都不是法律意见。2026-10-11 Grype 容器扫描已发现 Critical/High，Trivy 因数据库下载失败待重跑；镜像修复、逐包许可证核对和外部服务条款复核仍阻塞完整发布结论（见 [container-audit-2026-10-11.md](container-audit-2026-10-11.md)）。

## 凭证安全

- 真实 AK/Secret 只存在于运行环境 `.env`，不进入报告、截图、日志或版本库；`.env.example` 全部留空。
- 2026-10-08 扫描未发现已跟踪文件或 Git 历史中的高置信度凭证值；本地 `.env` 仍可能存在非空凭证且已被忽略，发布前必须确认它和数据库/WAL/SHM 不进入附件（证据索引 E-17）。
