# 算法与 API 策略一页纸

面向评审的 10 分钟版本；深入细节见各链接。所有坐标统一 BD-09，空间交换统一 GeoJSON（[../../../docs/adr/0010-统一坐标与空间交换格式.md](../../../docs/adr/0010-统一坐标与空间交换格式.md)）。

## 1. 地图 API 调用策略

- **坐标转换**：手工输入可明确选择 WGS84、GCJ-02 或 BD-09；WGS84/GCJ-02 分别通过百度 Geoconv V2 `model=2/1` 转换为 BD-09。Web API 单次最多 100 点，客户端按上限分块并校验返回数量、`x/y` 字段和有限数；项目内部及报告仍统一使用 BD-09。
- **地理编码/逆地理编码**：地址选点走 `/geocoding/v3`，中心点回填地址走 `/reverse_geocoding/v3`。
- **POI 检索**：每类设施按关键词表逐词请求 `/place/v2/search`（如菜市场=菜市场/农贸市场/生鲜超市），再按 uid、规范化名称与坐标去重，避免组合查询召回缺失（[../../../docs/adr/0009-百度地图调用的两阶段筛选策略.md](../../../docs/adr/0009-百度地图调用的两阶段筛选策略.md)）。
- **步行测算**：多坐标对走批量算路 `/routematrix/v2/walking`，按实测点对上限 100 分块；分块失败自动退化逐对 `/directionlite/v1/walking`；单坐标对保留 steps 折线供路线预览。
- **可靠性**：24h 坐标对缓存、全局 QPS 节流（默认 1.5）、有限重试与退避、超时/限流/格式错误分类计数、部分失败降级并在报告披露（[../architecture/v2-trustworthy-analysis.md](../architecture/v2-trustworthy-analysis.md)）。

## 2. 等时圈生成算法

- 以中心点为原点做 24（正式）/16（快速）方向**扇形采样**，首环合并为一次批量步行请求。
- 每方向用**二分细化**逼近"步行时间 = 阈值"的边界点；有效边界点 < 6 时降级为内置演示边界并显式标记。
- 输出闭合多边形与面积、采样数、成功数、最大耗时；真实路网结果与降级边界在报告字段中分开标识（[../../../docs/adr/0004-等时圈精度分档与报告导出.md](../../../docs/adr/0004-等时圈精度分档与报告导出.md)）。

## 3. POI 数据清洗与多源策略边界

- **当前运行时（2.3.0）**：只接入百度单一来源；按多关键词检索、语义归一和同源去重，规则版本写入报告 `facility_normalization`（[../architecture/v2.1-facility-normalization.md](../architecture/v2.1-facility-normalization.md)）。不能称为跨来源 POI 清洗。
- **已实现但默认关闭**：跨来源 `reconcile_facilities()` 纯计算模块，覆盖候选对齐、冲突保留、坐标系校验和待人工复核；未接入分析主链路，未用高德真实数据验证。策略见[多源 POI 对齐策略](../architecture/multi-source-poi-reconciliation.md)。
- **待完成**：高德 API Key、书面许可、真实双源样本和 50–100 对独立人工标签；当前没有多源准确率结果。
- 直线距离预筛（3000m）缩小步行计算候选集，控制 API 调用量。

## 4. 服务盲区识别算法

- 4×4 网格覆盖中心 ±1km；每格取"最近同类设施真实步行时间 > 阈值（默认 15 分钟）"与"格中心 1km 内无同类设施"两个条件。
- 两条件同时满足 = **重点服务盲区**；仅步行超阈值 = **设施稀疏区**；证据不足（检索失败/无候选/步行全失败）= **计算不完整**，不参与结论（[../../../docs/adr/0006-mvp设施类别与盲区判定标准.md](../../../docs/adr/0006-mvp设施类别与盲区判定标准.md)）。
- 2.1.0 起分级测算：核心四类（菜市场/药店/小学/医疗服务）跑网格；扩展三类（养老/公园绿地/便利超市）只算覆盖度与最近可达，以控制 API 成本。赛题盲区口径由核心类承载。

## 5. 评分与可解释性

- 类别分 = 数量 40% + 最近步行 40% + 空间分布 20%；综合分按有效类别配置权重归一化，数据不完整类别自动排除并披露原因（[../../../docs/adr/0011-可解释规则评分与数据质量提示.md](../../../docs/adr/0011-可解释规则评分与数据质量提示.md)）。
- AI 解读只读报告实体：证据引用校验 + 防幻觉过滤，无模型密钥时规则模板降级，不改变任何空间计算结果。

## 6. 性能特征（2.1.1 实测）

| 场景 | 总耗时 | API 调用 | 缓存命中率 |
| --- | --- | --- | --- |
| 冷缓存（无种子） | 124 s | 200 | 0% |
| 种子预热后首跑 | 19 s | 18 | 100% |
| 全缓存二次 | 12.5 s | 18 | 100% |

引入批量算路前同口径冷启动约 8 分钟；详见 [../performance/v2-baseline.md](../performance/v2-baseline.md)。
