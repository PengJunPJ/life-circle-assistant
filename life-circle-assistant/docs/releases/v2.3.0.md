# V2.3.0 候选发布说明

## 发布结论

`2.3.0` 是当前参赛候选版本，覆盖 V2.2.0 之后的坐标系转换、真实服务探活、Nginx 生产静态交付、GitHub 质量/安全/发布工作流和依赖漏洞修复。`v2.3.0` 标签尚未创建；只有本页列出的完整门禁全部通过后才具备锁版条件。

## 发布范围

- 坐标可信度：用户输入的 WGS84/GCJ-02 坐标由后端统一转换为百度 BD-09，并在响应中披露输入、输出、方法和降级状态。
- 服务探活：配置状态与真实 API 探测分离，避免仅凭 AK 存在就宣称地图服务可用。
- 生产交付：前端由 Node 构建后使用 Nginx 提供静态资源；后端运行镜像只安装生产依赖且不复制测试代码。
- 工程门禁：后端、前端和容器 job 必须全部成功；Python 生产/开发依赖与 npm high/critical 漏洞审计发现问题即阻断。
- 发布链路：语义化标签触发完整质量门禁、GHCR 镜像构建以及 SBOM/provenance 生成。

## 数据可信度边界

- 沙涌长盛花园 64/64 核查使用百度同源数据和相近规则，只能证明单社区同源一致性，不能宣传为跨来源准确率或整体泛化能力。
- 当前 POI 能力是百度单源下的多关键词检索、语义归一和同址去重；跨地图数据源的标识对齐、冲突处理和来源优先级尚未实现。
- 现有真实报告创建于 2026-10-04，早于本候选版；它不能单独证明 2.3.0 的最新真实运行结果。
- 离线快照、历史步行缓存与最新真实调用必须继续在界面、报告和演示中分开表述。

## 兼容性与回滚

- 报告主契约和核心分析接口保持兼容，坐标元数据为增量字段。
- 无百度凭证时继续使用离线快照；无模型密钥时继续使用规则模板。
- 回滚目标为已存在的 `v2.2.0`；回滚后不包含 2.3.0 的坐标转换、生产 Nginx 交付和新版门禁。
