# V2.1.1 发布说明

## 发布结论

`2.1.1` 是一次面向评审体验与评分细则的性能与可视化增强版本：步行测算接入百度批量算路显著降低冷启动耗时，报告新增类别得分雷达图，并通过随附步行缓存种子让干净环境首跑接近暖缓存速度。报告契约、盲区规则与地图提供方边界均不变，向后兼容。

## 发布范围

- 批量算路：多坐标对改走 `/routematrix/v2/walking` 一次取回矩阵，按实测点对上限 100 分块；分块失败自动退化逐对 directionlite，单坐标对仍走 directionlite 以保留 steps 折线供步行路线预览。
- 等时圈：首环 24/16 个方向采样合并为一次批量请求，边界二分细化保持逐方向单点。
- 雷达图：设施覆盖评分柱状图下方新增七维类别得分多边形，悬浮展示各类别得分，深浅主题各一套配色。
- 缓存预热：随附 `backend/data/walking_cache_seed.json`（2026-09-28 默认中心真实测算快照，2513 行）；启动时仅当步行缓存为空才导入，并按启动时刻重盖 TTL。`LIFE_CIRCLE_SEED_WALKING_CACHE=0` 关闭；`/api/health` 暴露 `seeded_walking_cache` 导入行数。
- 调用量口径：步行 API 调用改以客户端真实 HTTP 计数披露，批量分块不再少计。

## 数据可信度边界

- 缓存种子是历史真实测算快照，不是实时结论；导入行会通过报告缓存命中指标与 `walking_cache_used` 质量事件披露，评审可据此区分"种子命中"与"现场测算"。
- 需要最新真实测算时，清空 `walking_cache` 并设置 `LIFE_CIRCLE_SEED_WALKING_CACHE=0` 再运行。
- 扩展三类（养老、公园绿地、便利超市）仍不参与盲区网格测算，判定口径见 ADR006。

## 回滚与兼容性

- 报告契约（`2.0`）、公开接口与导出格式不变；`/api/health` 仅新增字段。
- 关闭种子开关或移除种子文件即回退为现场真实测算；雷达图为纯前端增强，移除不影响分析逻辑。
- 批量算路任一分块失败都会退化逐对调用，不会因新端点异常导致整矩阵失败。
