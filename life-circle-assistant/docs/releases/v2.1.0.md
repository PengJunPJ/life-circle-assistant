# V2.1.0 发布说明

## 发布结论

`2.1.0` 在 `2.0.0` 的可信分析骨架上完成三类增量：民生设施覆盖面、评分可读性和主题切换体验。它不改变报告契约、盲区判定规则和地图提供方边界，属于向后兼容的功能增强版本。

本版本仍为功能型 Beta：扩展类别不提供盲区结论，真实社区全网格基准仍为草稿，正式规划使用前需继续补齐多社区验证。

## 发布范围

- 设施类别：由四类扩充为七类，新增养老、公园绿地、便利超市；含百度逐词检索关键词、离线快照种子、地图图例与图层开关、报告柱状图与评分明细。
- 分级网格：核心四类（菜市场、药店、小学、医疗服务）继续执行 16 格服务盲区网格测算；扩展三类只计算覆盖度与最近可达，不生成服务区域网格，以控制步行 API 调用成本。判定标准与赛题盲区口径不变，详见 [ADR006](../../../docs/adr/0006-mvp设施类别与盲区判定标准.md)。
- 权重口径：类别权重再平衡至合计 100（18/18/18/16/10/10/10），综合评分仍按有效类别实际权重归一化。
- 评分可读性：设施覆盖评分柱状图新增悬浮提示，展示类别得分、设施数量、最近步行时间、综合权重与三个子项得分；数据无效类别附原因说明。
- 主题体验：深浅主题切换改为 View Transitions 羽化软边扩散过渡（420ms ease-out），从点击处晕染展开；不支持的浏览器或系统偏好减少动效时降级为颜色 crossfade，首屏不做过渡。

## 数据可信度边界

- 扩展三类的覆盖度与最近步行时间来自真实检索或离线快照，但不构成盲区结论；规划建议仍只引用核心四类盲区网格。
- 真实模式下核心四类网格在冷缓存时耗时较长（受百度 QPS 限流约束），步行缓存命中后显著加快；性能基线的七类口径复测尚未完成，见 [V2 性能基线与复测方法](../performance/v2-baseline.md) 的口径说明。
- 离线快照为合成样例，界面与报告保留"非实时数据"提示；真实社区全网格基准仍为 `draft`，不对外提供准确率、召回率或 F1。

## 回滚与兼容性

- 公开分析接口、报告契约（`2.0`）与导出格式均不变；七类设施通过请求 `categories` 字段显式选择，未传时后端默认仍为核心四类。
- 前端 `DEFAULT_CATEGORIES` 默认勾选七类；如需回退四类体验，取消三个扩展开关即可，不影响历史报告读取。
- 主题过渡为纯前端增强，移除后回退为即时切换，不影响任何分析逻辑。

## 发布后优先事项

1. 将当前分支推送并合并至 Gitee 主分支，使评审可拉取最新代码。
2. 在 Gitee 实跑 PR 质量门禁并完成保护分支绑定（含失败阻断反向验证）。
3. 完成真实社区 64 网格人工核查，将基准由 `draft` 转 `verified`。
4. 接入百度批量距离矩阵，降低核心网格冷启动耗时。
5. 按七类口径复测性能基线并更新文档数字。
