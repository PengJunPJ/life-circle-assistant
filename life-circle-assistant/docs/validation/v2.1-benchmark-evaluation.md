# V2.1 全网格基准评估指南

V2.1 将真实社区核查从“只抽查系统已发现的风险网格”升级为“先建立全网格人工真值，再评估系统预测”。这样才能同时发现误报和漏报，并计算准确率、召回率和混淆矩阵。

## 基准工作流

### 1. 导出待评估的体检报告

使用界面中的 JSON 导出，或从 `GET /api/report/{task_id}` 保存完整报告。基准中心、步行阈值、设施类别和网格规则必须与这份报告一致。

### 2. 生成人工标注模板

```bash
cd life-circle-assistant
python3 backend/scripts/evaluate_benchmark.py init \
  --report /path/to/report.json \
  --benchmark-id huangpu-community-a-20260921 \
  --community-name "黄埔区社区 A" \
  --output docs/validation/benchmarks/huangpu-community-a.json
```

生成器只复用网格清单和分析参数，不会把系统的 `kind` 填入标注文件，避免人工核查被系统结果先入为主。

### 3. 逐格标注真值

每个网格的 `expected_kind` 可填：

- `normal`：正常覆盖区。
- `sparse`：设施稀疏区。
- `critical`：重点服务盲区。

同时填写 `evidence.source`、`evidence.checked_at`、`evidence.reviewer` 和 `evidence.notes`。核查时应优先使用独立于系统预测的来源，并记录小区出入口、围墙、铁路、厂区和过街点等影响步行的现场条件。

全部网格完成后，将顶层 `status` 从 `draft` 改为 `verified`。工具会拒绝带有未标注网格的 `verified` 基准。

### 4. 生成评估结果

```bash
python3 backend/scripts/evaluate_benchmark.py evaluate \
  --report /path/to/report.json \
  --benchmark docs/validation/benchmarks/huangpu-community-a.json \
  --json-output docs/validation/results/huangpu-community-a.json \
  --markdown-output docs/validation/results/huangpu-community-a.md
```

草稿基准也可以运行，但指标只使用已标注网格，Markdown 会明确提示不得将其宣称为全网格准确率。

## 指标口径

- **准确率**：所有已标注网格中，系统分类与人工真值一致的比例。
- **精确率**：系统判为某类的网格中，真实属于该类的比例。
- **召回率**：真实属于某类的网格中，被系统正确识别的比例。
- **有效预测覆盖率**：已标注网格中，系统返回三种有效类别而非 `unknown` 的比例。
- **宏平均**：先分别计算正常、稀疏和重点盲区指标，再对三类等权平均，避免大量正常网格掩盖重点盲区识别不足。

`unknown` 不会被伪装为任意有效类别；它会降低预测覆盖率，并作为对真实类别的未命中结果降低召回率。

## V2.1 数据集建设要求

正式对外公布指标前，至少建立 3～5 个社区基准，覆盖不同设施密度、道路结构和社区类型。每个基准都应：

- 固定中心坐标、地址、核查日期、步行阈值和设施类别。
- 完成所有类别、所有网格的独立核查，不只复核系统报警区域。
- 保留人工证据来源和差异说明，不提交地图凭证或受限原始数据。
- 单社区指标与汇总指标分开报告，避免小样本结论被过度外推。

## 当前基准进度

首个真实社区草稿已生成：[`黄埔区红山街道海韵东路人工核查说明`](benchmarks/hongshan-haiyundonglu-20260921-review.md)。当前状态为 `draft`，64 个类别网格等待独立人工核查，因此尚未形成可对外公布的准确率、召回率或 F1。

沙涌长盛花园基准已完成 64 条百度地图同源人工复核，见 [`shachong-changsheng-20261004.json`](benchmarks/shachong-changsheng-20261004.json)。该结果与系统预测使用同一百度地图数据源和同一分类规则，100% 一致只能作为同源一致性证据；在补充独立来源或现场核查前，不应将其单独表述为跨来源准确率或普遍泛化成绩。
