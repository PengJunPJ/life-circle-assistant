# AI 全量补齐：真实 HTTP 离线浏览器验收

日期：2026-10-14。

脚本：`scripts/validate_completion_http.mjs`。浏览器不使用 `page.route` 或 `context.route` 拦截业务接口，连接实际 Vite 前端和 `app.main:app` 后端。启动使用临时 SQLite，显式关闭百度在线地图、高德验证、大模型、嵌入服务、OCR、原生等时圈及缓存播种；设施与历史路线来自随应用发布的本地快照。

## 运行

在 `life-circle-assistant` 目录执行：

```sh
node scripts/validate_completion_http.mjs
```

需要已安装的后端 `.venv`、前端依赖与 `playwright-core`。默认使用 macOS Google Chrome；其他 Chromium 可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定绝对路径。使用端口 8107、5177，若已有服务占用则停止，不结束用户进程。前端 `VITE_API_BASE_URL` 使用后端 origin，业务服务自行附加 `/api`。

标准出口明确标记为本地近似逆转换，不是官方或测绘级转换；现场精度值为未知。标准及旧出口、实际菜单下载结束后，持久化报告逐字段不变。

## 结果与清理

补齐标准导出后的最终完整运行退出码为 0。真实浏览器收到 31 个业务 API 响应，脚本直接收到 22 个 API 响应用于创建、查询、导出与结算校验（异步任务轮询次数会随运行速度变化）。页面错误、失败请求及外部服务请求均为 0。

脚本在输出 `passed` 前关闭 Chrome、停止自己创建的前后端子进程、确认两个端口释放，并删除本次精确的临时数据库目录；不修改开发数据库。

此验收证明真实前后端契约与浏览器操作闭环。它不证明外部账号权限、真实模型分类精度、真实 OCR 效果、现场路线精度或实际账单；这些需要使用已授权的服务及独立现场数据验收。
