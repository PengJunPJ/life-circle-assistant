# AI 空间能力补齐与验证记录

日期：2026-10-14。对应缺口核查 A3–A6 和 A11 的空间部分。源码和测试验证实现及契约；独立现场精度、真实配额收益与账号计费仍须使用合格数据另行核验。

## 已完成的业务链

| 缺口 | 现在的行为 | 正确性边界 |
|---|---|---|
| A3 原生等时圈 | 百度原生 `foot_fastest` / `foot_shortest` 的配置开关、能力状态、主动探测及正式分析适配。原生失败披露后退回径向路线采样。 | AK 与配置不等于账号授权；只有成功响应记录账号已核验。价格和现场边界精度保持未核验。原生失败不返回伪造几何。 |
| A4 主动测量 | 用户可请求预算内新增中心到网格的路线；风险优先、阈值附近及不确定性选点，逐次更新高斯过程。读取已审核障碍并映射到补测网格。 | 路线预算包含独立留出测量；失败、估算、未知缓存基础来源不作标签。原始秒数保留，预测不改评分或来源报告。 |
| A5 预测地图 | 返回观测点、可达观测中心的网格外沿、预测可达格、未决带和完整时间场五个图层。 | 观测只认证网格中心的路线；网格外沿不认证整个网格。模型标准差未经现场校准，估计区不作为事实。 |
| A6 缺口与候选 | 设施稀缺、步行超时、双条件重点缺口分别按四邻接成片；正式候选消费重点缺口组，另提供三种组的代表候选。 | 三种组允许重叠；失败路线和估算不能确认步行超时。保留原网格多片几何和未知洞，不用凸包填平。 |
| A6 障碍治理 | 可信来源、审核人和证据引用写入持久障碍边；中心点与网格版本限定范围，类别 ID 归一为空间网格 ID。正式分组与候选读取这些边。 | 原始居民留言及仅自称 `verified` 的数据不成为空间事实。无证据邻接明确标记为几何邻接，不能宣称路网连通。 |
| A11 空间评估 | 五种独立采样策略、同预算对照、独立社区和整体空间块留出、同误差预算比较及边界指标。 | 离线回放不等于实际 API 配额或延时收益。校准社区与评估社区隔离，不合并标签训练或调参。 |

内部地图和空间结果保持 BD-09。原生 Polygon / MultiPolygon 保留孔洞；适配器检查经纬度、闭合、非退化和处理上限，原生面积扣除孔洞。它不替代现场边界校验。

估算路线可以在来源已披露的模拟报告中展示，但不会因此产生“已确认步行超时”组或正式重点缺口候选。推荐层缺少可信重点缺口时返回 `calculation_incomplete`，避免输出空候选却声称可核验的规划建议。

## 原生能力配置与接口

环境变量 `BAIDU_NATIVE_ISOCHRONE_ENABLED=true` 开启尝试；真实模式还需要有效的百度账号与 AK。默认不启用。提供方只保存本进程内最近成功状态，成功过一次不保证后续请求、其他账号或额度仍可用。

官方文档：[等时圈 API 服务](https://lbs.baidu.com/docs/webapi?title=isochrone/guide/isochronicLines/base)，本次读取页面更新日期为 2026/04/01。端点 `/logistics_truck/v1/isochrone`，参数 `profile=foot_fastest|foot_shortest`、`point=经度,纬度`、`timeLimit=秒`、`inputCrs=bd09ll`、`outputCrs=bd09ll`。解析官方 `result.path` 坐标字符串；实际计费以账号权限、提供方报价和账单为准。

| 接口 | 输入与输出 |
|---|---|
| `GET /api/map/isochrone-capability` | 返回配置、凭证、账号最近核验、策略、来源和未核验费用披露；不发起原生请求。 |
| `POST /api/map/isochrone-probe` | `lng`、`lat`、`minutes`（1–60，默认15）、`strategy`（默认 `foot_fastest`）。未配置返回 `disabled / request_sent=false`；权限等失败返回 `unavailable` 和错误码，不补造 geometry。 |
| `POST /api/reports/{id}/experiments/active-sampling` | 已完成报告；`route_pair_budget`（2–200，默认20）、`grid_size`（3–15，默认9）、`strategy`、可选 `high_risk_grid_ids`。返回原始观测、预测、完整留出块、评估、预算和图层；不覆盖报告。 |

主动测量默认在中心周围1,250米跨度构造网格。`high_risk_grid_ids` 必须属于本次补测网格（例如 `r1c1`）；不能把正式报告4×4网格的类别 ID 原样当成9×9补测网格 ID。已审核正式障碍会按实际坐标自动映射，无需人工假定网格 ID 相同。

所有请求拒绝多余字段；测量预算、网格边长和原生分钟值拒绝布尔值/字符串自动转换。不存在或未完成报告返回404；超时返回504且来源报告保持不变。

## 独立空间评估

执行命令：

```sh
cd life-circle-assistant/backend
.venv/bin/python scripts/evaluate_spatial_sampling.py \
  --fixture tests/fixtures/spatial_sampling_contract.json \
  --budgets 6 12 20 \
  --json-output ../docs/validation/spatial-sampling-contract-2026-10-14.json
```

结果文件：[spatial-sampling-contract-2026-10-14.json](spatial-sampling-contract-2026-10-14.json)。这份 fixture 的 manifest 明确为 `synthetic_contract_only`，所有标签均人工构造，用于检查流程与预算，既不是地图实测，也不是现场标签。其两个社区各有22个采样点，五种策略分别按6、12、20路线对预算回放，共30次；外部请求数为0。

五种策略为主动高斯过程、径向扇区、均匀最远点、阈值附近规则加密、独立均匀采样加 IDW。各策略独立选训练点，在同社区使用相同500米整体留出块；独立 IDW 不复用主动样本。输出 MAE、假可达率、未决比例、训练与留出 ID、最小达标预算和相对于均匀策略的预算差。

边界指标是留出点近邻阈值跨越边中点的最大双向最近距离，不是连续等时圈或现场边界 Hausdorff 认证。没有真实或预测跨越时保持 `null`。数据无完整原始采集延时时，`recorded_latency_sum_ms` 保持 `null`；离线运行毫秒不得称作真实 API 延时。

当前合成回放并未证明主动策略优势：平坦合成社区所有策略在这些预算均未达到默认误差门槛，障碍合成社区主动与均匀最小达标预算相同，节省为0。上述结果不能推广到真实社区，预测仍关闭正式评分接入。

实际标签输入至少需要两个独立评估社区，明确 `real_api` 来源、采集时间、原始证据引用和正有限原始秒数；同坐标冲突须先处理。若有校准社区，至少另保留两个评估社区。拒绝插值/降级估算作为独立真值。

## 验证与仍需的外部证据

专项自动化测试覆盖：原生官方参数、几何与权限拒绝；补测实际调用、留出隔离、原始秒数、报告不变；公共 HTTP 请求严格校验；风险证据可信门禁；三类分组、未知洞、障碍拆分和候选消费；类别障碍 ID 归一与 upsert；独立策略/社区与标签门禁；服务区域、物理重试预算、候选出口及规划仿真回归。测试地图使用注入提供方或 MockTransport，不消耗真实账号配额。

空间、导出与仿真广泛专项回归共108项通过。随后增加“外层预算较大时，本次补测仍严格限制物理 HTTP 重试”的回归，相关13项通过；最终原生状态与补测原始秒数披露的29项专项全部通过。最近原生请求失败时能力状态会转为不可用，同时保留历史成功时间；所有路线均失败或估算时，不声称存在原始秒数标签。Ruff 检查通过。测试仅有 Starlette 使用 AnyIO 旧别名的弃用提示，无失败。

待补证据属于部署与效果验收：当前百度账号的原生授权与实际计费、真实独立社区和障碍两侧标签、现场通行边界、同误差真实路线配额与采集延时收益、后验不确定性校准、候选地块权属/入口/建设适用性。当前实现具备采集和评估入口，但不能将这些未取得的事实写为已验证。
