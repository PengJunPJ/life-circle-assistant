# MVP 设施类别与盲区判定标准

MVP 固定分析菜市场、药店、小学和医疗服务四类核心设施，养老服务与便利店只保留可扩展配置。服务盲区以目标网格点到最近同类设施的真实步行时间超过 15 分钟为主要标准，并以周围 1 公里内没有同类设施为辅助标准；两个条件同时满足时标记为重点服务盲区，仅满足设施缺失但仍可在 15 分钟内到达时标记为设施稀疏区。该规则区分了真实步行不可达和设施数量偏少两种不同问题。

两个条件的度量口径不同，须明确区分：

- **"周围 1 公里内"指以目标网格点（本格中心）为参考的球面直线距离（非步行距离），逐格独立判断**。同一处设施对不同网格是否算"1 公里内"可能不同；分析总中心点只用于确定 16 格的摆放位置，不参与该辅助判定。该直线距离条件用于快速粗筛设施缺失，实现上对应 `NEARBY_RADIUS_M = 1000` 与 `haversine_meters(cell.center, facility)`。
- **"步行时间超过 15 分钟"指从本格中心到最近同类设施的真实步行路线时间**，会受小区出入口、围墙、铁路、厂区、河道和过街点等绕行影响，不得用直线距离折算的时间代替。

## 2.1.0 修订：七类设施与分级网格测算

自 2.1.0 起，设施类别扩充为七类：在原有四类核心设施之上新增养老、公园绿地与便利超市三类扩展设施，以对齐赛题背景点名的"养老"服务、商务部一刻钟便民生活圈基本保障业态和上海 15 分钟社区生活圈导则的休闲绿地维度。

为控制步行 API 调用成本，网格测算分级执行：

- **核心四类（菜市场、药店、小学、医疗服务）**：继续执行 4×4 共 16 格的服务盲区网格测算，盲区与稀疏区判定标准不变。赛题"周边 1 公里内没有菜市场、药店或小学"的盲区口径由核心类承载。
- **扩展三类（养老、公园绿地、便利超市）**：只做设施覆盖度、最近步行时间与评分，不生成服务区域网格，因此不产出独立盲区结论，也不进入规划建议的盲区引用。每类由此省去 16×K 个步行坐标对（K 为预筛选候选数），在 1.5 QPS 限流下避免冷启动耗时线性膨胀。

类别权重合计保持 100：菜市场 18、药店 18、小学 18、医疗服务 16、养老 10、公园绿地 10、便利超市 10。综合评分仍按有效类别的实际权重重新归一化，单个类别数据不完整时自动排除并披露。

该分级是成本与评审口径的显式取舍：扩展类的价值在于覆盖评分、地图图层与规划模拟的调节杠杆，而非盲区判定。若后续需要扩展类的盲区结论，应为其单独开启网格测算并接受相应 API 成本，而不是默认全量开启。
