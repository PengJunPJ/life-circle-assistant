# 地图原生控件主题适配

## 需求

将百度地图原生导航、缩放和比例尺控件调整为与生活圈工作台一致的浅色、深色主题样式，同时保持原生交互功能。

## 设计方向

面向反复查看生活圈的地图工作台，采用紧凑、克制的悬浮工具风格。复用现有浅色灰绿和深色青绿配色，以细边框、圆角和轻量阴影统一视觉；交互反馈清晰，但不抢占地图图层的注意力。

## 验收标准

- 导航和缩放控件继续位于设施图例下方，不发生遮挡。
- 原生控件的背景、边框、图标和比例尺随浅色、深色主题切换，无须重新加载页面。
- 缩放、拖动缩放滑杆和地图导航保持可用，不修改地图供应商标识。
- 样式限定在地图容器内，不影响其他界面的按钮。
- 移动端保持控件可见、布局稳定。
- 导航控件的可视宽度为 36px，背景保持居中，不缩小原生点击区域；右边缘与上方设施图例对齐，并随工作台布局同步变化。移动端沿用顶部地图工具栏的 8px 右侧间距。
- 地图相关回归测试、类型检查、代码检查和生产构建通过。
