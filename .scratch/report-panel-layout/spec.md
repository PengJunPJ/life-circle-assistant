# 社区体检报告布局与图表完善

## 目标

降低右侧报告的阅读负担，按体检概览、设施详情、改善建议组织信息，并补齐页面和导出报告中的柱状图、雷达图、热力图。

## 验收标准

- 默认显示得分、结论、重点盲区及优先问题；历史、报告说明、导出使用独立入口。
- 部分结果、受限数据来源始终明确披露；技术指标及高德验证收进报告说明。
- 设施详情显示数量、最近步行时间和评分，计算过程可展开。
- 建议默认简洁展示，依据和候选点可展开；地图盲区选择自动展示对应建议。
- 改善模拟、智能助手按需打开，切页保留状态，候选点模拟自动展示结果。
- 默认显示柱状图，可切换雷达图与设施指标评分热力图；不将缺失评分当作零分；少于三类有效评分明确解释雷达图不可绘制的原因。
- PDF 包含同源数据生成的三类图表，缺失与不足数据明确标注。
- 桌面、窄屏手机、双主题可读，图表随容器尺寸、主题、报告和可见状态更新。

## 范围

保留历史搜索、重跑、比较、分页，所有导出格式及既有地图、模拟、助手能力；不改变评分算法和原始报告。
