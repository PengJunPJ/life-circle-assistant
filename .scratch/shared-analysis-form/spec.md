# 两个填写入口共用体检参数

## 目标

以紧凑、清晰的工作台布局完成“选地点或描述需求 → 检查同一套参数 → 开始体检”。沿用现有双主题、地图工作台和设施排序。

## 验收标准

- 默认自主设置，只展示当前填写入口；切换为一句话填写时保留地址、描述和公共参数。
- 自然语言只填公共地点、时间、精度和设施参数，不直接创建任务；未提及的参数沿用当前表单。
- 地址歧义在公共位置区展示候选；未确认位置、解析中、未发送的修改或无设施时阻止误启动。
- 经纬度、坐标系和精度放入高级设置；数据状态显示简短摘要，详情可展开，异常与快照边界保持可见。
- 左侧设施仅决定下一次体检范围。地图工具栏独立管理报告设施、全选展示／全部隐藏和服务区域开关，未体检类别禁止直接展示。
- 左侧底部固定唯一启动按钮，随时显示当前地点、时间和设施数量；满足原报告参数且仅新增类别时通过同一个按钮补充体检，失败保留原报告。
- 在 1440×900 默认首屏可见地点、时间、设施与启动按钮；检查手机、较窄窗口和深浅主题，无横向溢出。

## 设计方向

面向社区体检用户，保留安静、紧凑的工具界面：缩短标题与状态区域，以公共参数为主，固定摘要与操作区提供稳定的确认位置。不引入新的组件库或装饰资产。
