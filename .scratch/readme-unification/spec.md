# 统一项目 README 入口

Status: ready-for-agent

## 目标

根 README 作为统一入口，集中维护项目介绍、环境变量、安装部署和开源信息；应用 README 精简为简介与导航，技术细节迁入文档目录。

## 范围

更新两份 README、技术文档入口与本地追踪文件。基于应用 README 当前工作区内容迁移，保留其中独有说明，不丢弃已有未提交成果。不修改应用行为，不提交或推送 Git。

## 验收条件

- 根 README 包含项目定位、功能、预览、技术栈、安装配置、部署运维、文档索引、限制、贡献及许可。
- 应用 README 仅包含应用目录简介及导航，不再维护重复安装步骤和环境变量表。
- 原功能与接口、快照、缓存、导出、性能评估及材料生成说明在技术文档中保留。
- 迁移后本地路径、跨文件目录锚点、命令语法与环境变量覆盖检查通过。
- 默认离线样例与代码和快照一致。
