# 设施图层快捷选择与图例联动

在“设施与服务区域”中增加“全选”和“全部取消”快捷操作，一次更新七类设施的选择状态、计数及地图展示。已全选时禁用“全选”，未选择任何设施时禁用“全部取消”。服务区域状态开关仍单独控制。

桌面与移动端设施图例只显示已勾选类别，顺序与设施列表一致。规划候选点图例随对应类别及实际候选点显示；假设设施与模拟区域沿用当前独立展示逻辑。没有设施、候选点或模拟图例时隐藏桌面的空图例条。

沿用现有青绿色、紧凑样式，兼容浅色与深色主题、桌面与移动端，并支持键盘操作。

初始化时默认选择医疗服务、学校、购物、养老四类设施，计数为 4/7；“全选”仍选择全部七类设施。

设施列表与地图图例统一按以下顺序展示：医疗服务、学校、购物、养老、菜市场、药店、公园绿地。默认勾选项排在前四位，“小学”展示名称改为“学校”，“便利超市”展示名称改为“购物”，购物图标使用“购”。
