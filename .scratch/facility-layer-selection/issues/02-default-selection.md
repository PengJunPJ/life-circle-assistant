# 初始化默认选择四类设施

Status: resolved

## 需求

用户要求初始化时默认勾选基础医疗、教育、购物、养老。按现有类别映射为医疗服务、小学、便利超市、养老，初始计数与图例显示四类。

## 实现

将全部可选类别与默认勾选类别分开配置。“全选”、设施列表及图例筛选继续使用全部七类；初始化状态使用上述四类。首次使用向导同步说明四类默认设施。

## 验证

- 前端代码检查、类型检查、68 项既有测试和生产构建均通过。
- 浏览器验证 1440 像素桌面及 390 像素手机：首次打开及刷新页面均默认勾选四类，计数为 4/7，桌面与手机图例一致。
- “全选”仍选择七类，全部取消后计数为 0/7 且设施图例条隐藏；页面无运行错误。
