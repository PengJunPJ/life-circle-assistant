# 在概览保留验证状态并提供详情入口

Status: ready-for-human
Type: task

## 问题

报告布局优化后，高德辅助验证移入“报告说明”，概览没有状态提示；缺少验证字段的旧报告完全隐藏该章节，用户容易误以为功能消失。

## 实现

在概览增加整行可点击的状态入口，点击直接打开并定位验证详情；旧报告展示未进行辅助验证的明确说明。
