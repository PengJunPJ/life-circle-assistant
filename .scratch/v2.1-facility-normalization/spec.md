# V2.1 设施语义归一化

V2.0 已将菜市场和医疗服务的多关键词拆分请求，但不同关键词仍可能返回同一机构的主体、门诊、科室或同址别名。这会虚增设施数量，进而影响评分、网格候选和规划建议。

V2.1 建立提供方无关的设施语义归一化模块：

- 标准化全半角、空白与标点，保留可读原始名称。
- 将核心设施分为稳定的语义子类。
- 对同提供方标识重复项以及 80 米内同机构的主体/下属门诊进行合并。
- 保留别名、原始记录标识、合并方法和可审计统计。
- 归一化后的设施统一供步行计算、评分、服务区域、报告和导出使用。

## 安全边界

- 不仅因坐标相近就合并不同名称机构。
- 药店门店名、学校校区名和菜市场名保留为独立设施。
- 不将名称推断冒充提供方官方分类，报告明确标注规则版本。
