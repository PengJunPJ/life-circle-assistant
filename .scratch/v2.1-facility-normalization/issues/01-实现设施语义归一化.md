# 01：实现设施语义归一化

Status: resolved

## 验收项

- [x] 提供单一归一化 interface，返回设施列表和审计摘要。
- [x] 识别菜市场、药店、小学和医疗服务语义子类。
- [x] 合并同一机构的同址主体与下属门诊，保留别名和原始标识。
- [x] 不合并异地同名机构或同址不同机构。
- [x] 报告和 CSV 导出披露规范名称、语义类型和合并结果。
- [x] 通过专项测试与完整质量检查。

## Answer

已新增纯计算模块 `normalize_facilities(facilities)`，在设施检索后、步行计算与评分前统一执行名称标准化、语义分类和同址同机构合并。报告顶层写入归一化摘要，每个设施保留规范名称、语义类型、别名、合并方法、置信度和原始标识；CSV 同步披露关键审计字段。

合并规则覆盖同 provider ID、80 米内同名设施，以及医疗主体与发热门诊、急诊科、预防接种门诊等下属记录。异地同名、同址不同机构、不同药店分店保持独立；缺失 provider ID 的记录不会被误判为同一设施。
