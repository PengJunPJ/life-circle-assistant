# AI 事实校验与语义审核

Status: resolved
Type: task

## 目标

统一生成式出口的事实槽位校验，修复有效报告引用夹带虚构分数/分钟的问题；实现类别与实体分离的设施语义辅助审核。

## 验收

错误、未知、跨报告槽位不能进入事实答复；模型自由文本不能改事实；语义不确定项保留待审核，不修改原报告；FakeProvider 回归通过。

## Answer

普通报告解读与规划问答统一使用服务器事实目录，模型只选择报告/对象/槽位，不能附带事实值或自由文本。语义分类与实体关系分开审核，保留原字段证据；嵌入提供注入接口，审核不改正式数据。模型预算按实际 HTTP 尝试含重试计数；设施归一化聚合多源与入口证据并保持幂等。

事实、语义、模型预算及规划相关专项回归通过；最终后端全量 366 项测试通过。详细证据见 `life-circle-assistant/docs/validation/ai-first-implementation-2026-10-13.md`。
