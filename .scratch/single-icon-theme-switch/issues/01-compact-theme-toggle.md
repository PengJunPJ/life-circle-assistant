# 主题切换改为单图标按钮

Status: ready-for-human

## 问题

顶栏主题切换同时展示两个图标，占用空间，用户要求改为单图标模式。

## 实现

显示目标主题对应的图标，点击后在深浅主题之间切换，并同步悬停提示与无障碍名称。按钮沿用现有配色，保持固定尺寸与居中布局。
