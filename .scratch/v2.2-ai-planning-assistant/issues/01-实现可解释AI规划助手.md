# 01：实现可解释 AI 规划助手

Status: ready-for-agent

## 任务概述

在现有 15 分钟生活圈结构化体检报告之上增加可解释 AI 规划助手。AI 负责摘要、服务区域解释、有限范围规划问答和汇报摘要；地图事实、步行时间、等时圈、评分和盲区分类继续由确定性分析引擎负责。

## 验收项

- [ ] 完成报告证据索引，能够定位报告、民生设施类别、服务区域网格、设施实体、类别评分、数据质量事件和规划模拟结果。
- [ ] 提供结构化 AI 解读服务，至少支持报告摘要、网格/盲区解释、规划优先级、候选设施影响解释和汇报摘要。
- [ ] AI 结果包含摘要、建议、证据引用、模型或降级模式、提示词版本、生成时间和数据质量提示。
- [ ] 真实模型通过后端适配器可选接入，模型密钥不下发浏览器；未配置模型时可使用规则模板完成 Docker 离线演示。
- [ ] 服务校验所有证据引用和事实性指标，过滤或降级未知设施、未知网格、虚构评分、虚构步行时间和超出报告范围的内容。
- [ ] 模型未配置、超时、限流、网络错误或返回无效结构时，原始体检报告仍可用，并返回可读的规则降级或未生成状态。
- [ ] 页面显示 AI 生成方式和数据质量说明，并明确 AI 不会修改原始评分、路线和设施数据。
- [ ] 历史报告重新打开时可以读取同一报告版本的 AI 解读；重新运行的新报告不会误用旧解读。
- [ ] JSON/PDF 导出可附加 AI 结果、证据引用和生成方式，同时保留原始报告字段。
- [ ] 后端、前端和导出自动化测试覆盖完整报告、部分失败、快照/缓存、模型错误、防幻觉引用和无密钥降级场景。

## 约束

- 不让 AI 直接调用百度地图或替代任何确定性空间分析规则。
- 不把模型生成的自然语言当作未经校验的地图事实。
- 不要求日常 CI 配置真实模型 API 密钥；真实模型集成测试必须显式启用且不得记录敏感信息。
- 沿用现有 Vue、TypeScript、Vite、FastAPI、SQLite 和报告 API 边界，不新增独立微服务。

## 建议拆分

1. 固化报告证据索引和结构化解读契约。
2. 实现规则模板提供方及公开后端服务。
3. 增加可选模型适配器、超时重试和输出校验。
4. 接入报告页面、证据展开和数据质量提示。
5. 接入历史报告与 JSON/PDF 导出。
6. 完成自动化、安全和回归测试。
