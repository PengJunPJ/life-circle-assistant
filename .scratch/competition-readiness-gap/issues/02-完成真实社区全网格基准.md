# 02：完成真实社区全网格基准

Status: ready-for-agent

## 任务概述

以地址、坐标和设施语义一致的黄埔区样例社区为基准，完成四类设施 × 4×4 网格共 64 个类别网格的独立盲审，生成可审计的分类指标，并修正或剔除与真实场景不一致的合成快照叙述。

## 验收项

- [ ] 固定中心地址、BD-09 坐标、核查日期、15 分钟阈值、设施类别和网格规则。
- [ ] 盲审模板不包含系统预测分类，所有 64 个网格均填写人工分类和证据。
- [ ] 证据记录来源、时间、核查人、最近设施、有效步行时间和道路障碍。
- [ ] 基准状态只有在 64 个网格完成后才能变为 `verified`。
- [ ] 生成准确率、精确率、召回率、F1、宏平均、混淆矩阵和有效预测覆盖率。
- [ ] 单社区指标与汇总指标分开陈述，不把小样本外推为总体准确率。
- [ ] 离线合成快照、真实 API 报告和人工真值在名称、来源和界面提示中明确区分。
