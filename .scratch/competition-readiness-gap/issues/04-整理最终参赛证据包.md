# 04：整理最终参赛证据包

Status: ready-for-agent

## 任务概述

把已有代码、文档、真实报告、性能记录和限制说明整理为评审人员可按顺序复现的交付包，覆盖离线演示、真实百度模式、算法说明、API 调用策略、POI 清洗、盲区规则、工程质量和许可证。

## 验收项

- [ ] README 明确项目定位、赛事要求映射、离线/真实模式、环境变量、Docker 启动、测试和导出入口。
- [ ] 提供不需要凭证的完整离线演示流程和一条受控真实模式流程。
- [ ] 记录真实模式的 API 调用量、缓存命中率、耗时、失败/降级和数据质量提示。
- [ ] 技术文档覆盖地理编码、POI 检索、步行路线、等时圈采样、POI 归一化、服务区域分类和评分规则。
- [ ] 对比测试报告明确中心点、日期、设施口径、人工方法、指标和限制。
- [ ] 许可证、环境变量示例和 Docker 配置可从干净环境复现，仓库不含任何真实凭证。
- [ ] 现场演示顺序固定为：启动 → 选点 → 分析 → 查看等时圈/盲区 → 评分/建议 → 模拟 → 导出 → AI 解读。
- [ ] 对未完成基准、未开通 Gitee 门禁和 AI 数据边界做诚实标记，不把草稿或配置文件描述为已验证能力。
