# V2.1 真实百度地图页面测试与首次使用向导

让首次使用者能在页面上明确确认当前是否已启用正式百度地图 Web 服务和 JavaScript 底图，并按“确认数据源→选择中心点→设置参数→开始体检→查看结果”完成首次测试。

## 范围

- 页面显示后端真实 API 状态和百度底图加载状态。
- 首次访问自动打开分步向导，顶部提供可重新打开入口。
- 向导覆盖数据源、中心点、分析参数、启动体检和结果阅读。
- 取消页面加载后自动分析，避免误消耗真实 API 配额。
- 本机配置切换为真实百度地图模式，不在页面暴露后端 AK 或 Secret。

## 验收标准

- 真实模式下页面能显示“Web 服务已连接”和“百度底图已加载”。
- 快照模式或底图加载失败时明确显示非实时或检查白名单提示。
- 向导只在本浏览器首次自动打开，用户可随时重新打开。
- 手机端向导会自动打开对应的参数或报告面板。
- 前端类型检查、单元测试和构建通过。
