# V2.1 全网格基准评估

V2.0 已能识别按设施类别划分的正常覆盖区、设施稀疏区和重点服务盲区，但真实社区核查只覆盖系统已标出的 13 个风险网格，无法计算全网格准确率、召回率和混淆矩阵。

V2.1 第一阶段建立可复用的社区基准数据与评估工具链：

- 从体检报告生成不带模型预测答案的全网格人工标注模板。
- 明确标注状态，未完成标注不得冒充已验证基准。
- 对已标注网格计算混淆矩阵、准确率、精确率、召回率、F1 和有效预测覆盖率。
- 同时输出机器可读 JSON 和适合评审阅读的中文 Markdown 报告。
- 保持 V2.0 公开报告契约不变。

## 验收标准

- 可以从含 `service_areas` 或 `zones` 的 V2 报告生成基准模板。
- 基准文件检查网格编号、类别、数量、重复项和审核状态。
- 未标注项不进入指标分母，报告必须展示标注完成度。
- 系统返回 `unknown` 时计入未决结预测，并作为对真实类别的假阴性影响召回率。
- 至少覆盖完全正确、分类错误、`unknown`、部分标注、网格缺失和非法基准的自动化测试。
