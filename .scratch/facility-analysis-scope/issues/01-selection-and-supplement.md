# 设施体检范围与地图展示选择

Status: ready-for-human
Type: task

## 问题

设施勾选同时作为体检请求范围和地图展示筛选。四类体检完成后，全选会展示七类图例，但报告没有另外三类的数据；全部隐藏还会使重新体检请求失去原有类别。

## 实现

已完成。分离体检范围与地图展示状态，限制本报告的可展示类别，提供显式的按需补充体检入口。补充沿用原报告参数并生成合并范围的新报告，成功后保留原有隐藏选择并展示新增类别，失败保留原报告与补充选择以便重试。
