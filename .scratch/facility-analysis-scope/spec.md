# 按需体检与设施展示分离

## 目标

保留按需体检。体检前选择参与分析的民生设施类别；体检后勾选只控制本报告已分析类别的地图展示，未分析类别明确标注“未体检”。

## 验收标准

- 默认选择医疗服务、小学、购物、养老，保留七类设施的现有排序。
- 体检后的“全选展示”只选择本报告已分析的类别；全部隐藏不改变体检范围、评分或报告图表。
- 未参与本报告的类别标注“未体检”，不能直接打开对应地图图层或出现在设施图例中。
- 用户可选择未体检类别并主动发起补充体检；沿用原报告的位置、步行时间、分析精度，合并原有类别生成新报告。
- 补充体检成功前不开放新增图层；失败时保留原报告、原体检范围与地图展示选择，允许重试。
- 历史报告、自然语言发起体检及重新体检均使用各自的完整分析范围，不受地图隐藏操作影响。
- 验证四类报告的全选、隐藏、补充成功/失败，以及移动端和双主题的展示。

## 实现边界

复用现有完整体检接口生成合并范围的新报告，避免直接拼接来自不同任务的评分、服务区域和建议。本轮只调整设施范围与展示行为。
