# 可调用工具的规划助手

在已完成的体检报告中，以自然语言调用设施查询、网格证据、规划候选点和单点规划模拟。沿用现有 LLM 配置，使用原生 function calling；模型负责选择工具与解释，计算由后端执行。

## 验收

- 模型工具请求实际执行，返回结果后可继续选择下一工具。
- 仅能访问当前报告；类别、网格、候选点和用户地图选点由服务端校验，模型不能生成坐标。
- 每轮最多六次工具调用、一次模拟，模型循环和整体请求有上限。
- 显示调用参数、实际结果、来源、失败状态与可定位的证据；改善量来自已有模拟服务。
- 多轮追问使用服务端保存的上一轮结果；切换报告时隔离上下文与过期响应。
- 模型关闭或失败时明确标记规则模式/降级，执行过的结果保留，不重复模拟。
- 原始报告、设施与评分不变；助手模拟可展示在现有地图和模拟面板。
- 测试覆盖多轮工具链、错误参数、虚构证据、失败/预算、保存与 UI 状态；更新使用文档。

## 范围

本次完成工具规划助手；不实现多方案自动比较或自动写入设施主数据。
