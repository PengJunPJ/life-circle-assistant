# 一键构建、测试与离线演示

用户要求：提供评审可快速跑通的一键编译／部署脚本、示例数据、自动化测试，以及镜像离线分发方式。

## 验收标准

- 在仓库根或应用目录执行 `bash demo.sh` 即可构建、等待健康、验证链路并准备七类设施示例报告。
- 宿主机仅要求 Bash 与 Docker Compose，不依赖 Python、Node.js、地图密钥或模型密钥。
- 演示固定使用离线合成样例，独立 Compose 项目和数据卷，不读取或覆盖开发 `.env`。
- 再次启动复用匹配的历史样例；`test` 显式生成新报告并验证导出与前端代理；`stop` 保留数据。
- `package` 导出带架构信息、许可证、配置、脚本与镜像的离线包；解压后 `load` 无需源码、构建和镜像拉取即可启动。
- 提供中文操作文档并接入现有容器质量门禁。
