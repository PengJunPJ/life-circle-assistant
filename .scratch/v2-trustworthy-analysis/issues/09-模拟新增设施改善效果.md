# 09：模拟新增设施的改善效果

**要构建的内容：** 允许用户在规划候选位置加入一个假设民生设施，并直观看到新增设施前后的类别评分、覆盖范围和服务盲区变化，以支持规划方案比较。

**阻塞于：** 08：生成有依据的规划建议

Status: ready-for-human

- [ ] 用户可以从规划建议选择候选位置，也可以在地图上指定假设设施位置。
- [ ] 用户可以为假设设施选择民生设施类别。
- [ ] 模拟结果重新计算受影响类别的覆盖、服务区域和评分。
- [ ] 界面并列展示模拟前后的类别评分、综合分、覆盖面积和服务盲区数量变化。
- [ ] 地图能够区分来源设施、假设设施以及模拟后的服务区域。
- [ ] 模拟不会修改来源民生设施数据或原始体检报告。
- [ ] 用户可以清除模拟并恢复原始报告视图。
- [ ] 自动化测试验证假设设施只影响对应类别且原始数据保持不变。
