# 07：持久化分析任务与历史报告

**要构建的内容：** 将体检任务、请求参数和完成报告持久化，使用户在服务重启后仍能浏览历史报告，并可以使用历史参数重新运行分析。

**阻塞于：** 02：建立可替换的地图提供方与可解释报告骨架

Status: ready-for-human

- [ ] 分析任务、请求参数、任务状态、完成报告和错误信息保存到 SQLite。
- [ ] 服务重启后已完成和已失败任务仍可查询。
- [ ] 服务异常重启时遗留的运行中任务被标记为中断或安全恢复，不会永久显示为运行中。
- [ ] 用户可以按时间和分析中心浏览历史报告列表。
- [ ] 用户可以打开一份历史报告并恢复其完整地图和报告内容。
- [ ] 用户可以使用历史报告的相同参数发起新的分析任务。
- [ ] 任务列表和报告查询具有明确的空状态、加载状态和失败状态。
- [ ] 自动化测试通过重新初始化存储层验证任务和报告持久存在。
