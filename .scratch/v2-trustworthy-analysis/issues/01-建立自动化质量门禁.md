# 01：建立自动化质量门禁

**要构建的内容：** 建立覆盖后端、前端和容器交付的自动化质量门禁，使后续第二版改动能够在不依赖真实地图凭证的情况下持续验证，并在回归进入主分支前给出明确失败信息。

**阻塞于：** 无（可立即开始）

Status: ready-for-human

- [ ] 自动化流程能够运行现有后端测试，并在测试失败时阻断。
- [ ] 自动化流程能够执行前端类型检查、前端测试和生产构建，并在任一环节失败时阻断。
- [ ] 自动化流程能够构建容器并完成最小健康检查或演示模式冒烟验证。
- [ ] 默认自动化流程使用本地快照模式，不要求配置百度地图凭证。
- [ ] 项目文档说明本地运行质量检查的统一命令以及自动化流程包含的检查项。
- [ ] 当前已有功能在质量门禁启用后保持测试通过和生产构建成功。
