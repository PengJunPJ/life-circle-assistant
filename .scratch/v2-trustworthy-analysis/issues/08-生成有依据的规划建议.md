# 08：生成有依据的规划建议

**要构建的内容：** 根据类别评分和重点服务盲区生成可追溯的规划建议，使用户知道应改善哪类民生设施、优先处理哪个区域以及预期能够改善多大范围。

**阻塞于：** 03：修正并解释体检评分；04：按设施类别识别服务盲区

**状态：** ready-for-agent

- [ ] 每条规划建议关联一个明确的民生设施类别。
- [ ] 每条规划建议引用一个或多个实际重点服务盲区，不根据无关类别生成建议。
- [ ] 建议包含优先级、问题依据、最近同类设施情况和目标改善范围。
- [ ] 系统可以在重点服务盲区内或附近生成可解释的候选位置。
- [ ] 候选位置包含坐标、关联区域以及被选中的原因。
- [ ] 没有服务短板时报告明确说明无需生成补充设施建议，而不是显示异常空白。
- [ ] 地图和报告可以相互定位规划建议与对应服务盲区。
- [ ] 自动化测试验证建议类别、区域引用、优先级和候选位置均来自实际分析结果。
