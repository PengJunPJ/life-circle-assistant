# 05：统一地址、地图与坐标选点

**要构建的内容：** 让用户可以通过地址候选、地图点击或经纬度输入确定唯一的分析中心点，并确保输入控件、地图标记、分析请求和体检报告始终使用同一位置。

**阻塞于：** 02：建立可替换的地图提供方与可解释报告骨架

Status: ready-for-human

- [ ] 用户输入地址后可以查看并选择明确的候选结果。
- [ ] 用户可以通过地图点击更新分析中心点。
- [ ] 用户可以输入合法的 BD-09 经纬度确定分析中心点。
- [ ] 地址、坐标、地图标记和分析请求在任一选点方式后保持同步。
- [ ] 选点后能够显示逆地理编码得到的确认地址；无法获取地址时仍明确展示坐标。
- [ ] 无效坐标、无法解析的地址和超出支持范围的地点会给出明确提示并阻止错误分析。
- [ ] 本地快照模式只允许明确支持的样例位置，不伪装支持任意地址的真实分析。
- [ ] 前端集成测试覆盖三种选点方式以及选点后提交分析的完整流程。
