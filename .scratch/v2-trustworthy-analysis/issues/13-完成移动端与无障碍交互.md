# 13：完成移动端与无障碍交互

**要构建的内容：** 使生活圈体检工作台在移动端保持地图优先，并让键盘用户能够完成选点、分析、查看服务盲区和阅读规划建议的主要流程。

**阻塞于：** 05：统一地址、地图与坐标选点；08：生成有依据的规划建议

Status: ready-for-human

- [ ] 移动端视口不存在页面级横向溢出。
- [ ] 移动端以地图作为主要区域，分析参数通过底部抽屉访问。
- [ ] 体检报告通过独立可展开面板访问，不会长期遮挡整个地图。
- [ ] 移动端可以完成选点、修改参数、运行分析、查看区域说明和阅读规划建议。
- [ ] 图例、地图工具栏和导出操作在小屏幕下不会相互遮挡。
- [ ] 所有主要交互具有可访问名称，并可使用键盘到达和操作。
- [ ] 加载、完成、失败和部分结果状态能够被辅助技术识别。
- [ ] 响应式自动化测试至少覆盖一个桌面视口和一个移动端视口。

## 浏览器实测说明

已在 V2 实现阶段使用本地 Vite 页面完成桌面与 390px 移动视口实测，核对地图优先布局、底部参数/报告入口、面板展开收起、页面横向溢出和 Escape 返回地图。自动化测试继续保留 CSS 断点契约，并新增 Vue + jsdom 渲染状态测试，覆盖移动面板打开、遮罩显示与 Escape 收起。
