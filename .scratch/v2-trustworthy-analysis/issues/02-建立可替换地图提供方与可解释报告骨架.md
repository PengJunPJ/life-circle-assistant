# 02：建立可替换的地图提供方与可解释报告骨架

**要构建的内容：** 在保持现有体检流程可运行的前提下，建立统一的地图能力边界和可扩展报告契约，使真实地图、本地快照和测试夹具能够以一致方式提供地理编码、民生设施检索和步行计算结果，并让用户看到报告的数据来源和质量情况。

**阻塞于：** 01：建立自动化质量门禁

**状态：** ready-for-agent

- [ ] 地理编码、民生设施检索和步行计算通过统一的地图提供方边界调用。
- [ ] 默认测试能够替换地图提供方并返回确定性结果，不访问真实百度地图服务。
- [ ] 现有演示模式和真实地图模式继续通过同一公开分析任务流程工作。
- [ ] 分析报告包含任务阶段、数据来源、计算模式、部分失败和数据质量事件。
- [ ] 前端可以打开数据质量说明，查看真实 API、缓存、本地快照、插值或降级估算的使用情况。
- [ ] 数据质量说明不会把本地快照或降级结果描述为最新真实地图测算。
- [ ] 公开分析接口保持兼容，或为必要的契约变化提供清晰迁移说明。
