# 03：修正并解释体检评分

**要构建的内容：** 修正体检评分的边界行为，并把每类民生设施的数量、最近步行时间和空间分布子分数展示给用户，使综合生活圈指数能够被核验和解释。

**阻塞于：** 02：建立可替换的地图提供方与可解释报告骨架

Status: ready-for-human

- [ ] 没有有效设施的类别不会获得正的最近步行时间分数，也不会出现异常高的类别总分。
- [ ] 每类民生设施报告数量、最近步行时间和空间分布三个子分数。
- [ ] 每个子分数包含实际权重、计算结果和可读的得分或扣分原因。
- [ ] 综合分只根据有效的已选类别计算，并记录实际采用的类别权重。
- [ ] 类别数据缺失或计算失败时与真实覆盖较差明确区分。
- [ ] 有效类别不足时报告标记为部分结果，不展示具有误导性的综合分。
- [ ] 前端体检报告能够展开查看类别评分构成和计算说明。
- [ ] 自动化测试覆盖零设施、单个近距离设施、多个分布良好设施、步行数据缺失和类别部分失败。
