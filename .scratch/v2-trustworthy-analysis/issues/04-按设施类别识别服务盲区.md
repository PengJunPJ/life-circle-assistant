# 04：按设施类别识别服务盲区

**要构建的内容：** 针对每个选定民生设施类别独立计算网格步行可达性，生成正常覆盖区、设施稀疏区和重点服务盲区，并允许用户在地图上查看每个区域的判定证据。

**阻塞于：** 02：建立可替换的地图提供方与可解释报告骨架

**状态：** ready-for-agent

- [ ] 菜市场、药店、小学和医疗服务分别生成自己的服务区域分类结果。
- [ ] 直线距离只用于候选预筛选，真实模式的最终分类使用最近同类设施的步行结果。
- [ ] 重点服务盲区同时满足超过步行阈值和周边范围内缺少同类设施的规则。
- [ ] 设施稀疏区表示局部缺少同类设施但仍能在步行阈值内到达，且不被误标为重点服务盲区。
- [ ] 服务区域以 BD-09 GeoJSON 输出，并包含类别、区域类型、最近设施、步行时间、步行距离、数据来源和判定依据。
- [ ] 地图支持按设施类别和区域类型控制图层显示。
- [ ] 用户点击区域后可以查看该区域的分类依据和最近同类设施信息。
- [ ] 自动化测试覆盖无同类设施、一公里内但超时、一公里外但阈值内可达、正常覆盖、多类别同网格和部分步行结果失败。
