# 12：比较两份体检报告

**要构建的内容：** 允许用户从历史记录中选择两份已完成报告，比较不同地点、日期或分析参数下的覆盖和评分变化。

**阻塞于：** 03：修正并解释体检评分；04：按设施类别识别服务盲区；07：持久化分析任务与历史报告

Status: ready-for-human

- [ ] 用户可以从历史列表中选择两份已完成报告进行比较。
- [ ] 比较界面展示分析中心、生成时间、步行阈值、分析模式和设施类别差异。
- [ ] 比较结果展示综合分、类别分、可达面积、民生设施数量和服务区域数量变化。
- [ ] 类别选择不同或某类别数据无效时，比较界面明确说明不可直接比较的部分。
- [ ] 用户可以从比较结果返回任一原始报告。
- [ ] 系统限制一次比较两份报告，并对选择不足、重复选择或无效报告给出提示。
- [ ] 自动化测试覆盖同地点不同时间、不同地点、不同类别组合和部分报告的比较。
