# 11：生成可分享的 PDF 体检报告

**要构建的内容：** 将体检结果生成排版稳定、适合评审和汇报的 PDF 报告，使非系统用户也能理解分析范围、核心问题、规划建议和数据可信度。

**阻塞于：** 10：导出 JSON、CSV 与 GeoJSON

**状态：** ready-for-agent

- [ ] PDF 包含报告标题、分析中心、生成时间、步行阈值、分析模式和设施类别。
- [ ] PDF 包含等时圈与服务盲区地图、综合评分、类别评分和核心汇总指标。
- [ ] PDF 包含重点服务盲区说明和规划建议，并能关联具体设施类别。
- [ ] PDF 明确披露数据来源、计算模式、部分失败、缓存或降级估算情况。
- [ ] PDF 在常见页面尺寸下无文字裁切、内容重叠、乱码或不可读图表。
- [ ] 报告界面可以触发 PDF 导出并显示生成状态和错误提示。
- [ ] 自动化检查验证 PDF 包含关键文本和预期页数范围，并通过渲染检查主要页面。
