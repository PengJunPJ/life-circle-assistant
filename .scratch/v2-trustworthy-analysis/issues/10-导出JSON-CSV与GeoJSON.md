# 10：导出 JSON、CSV 与 GeoJSON

**要构建的内容：** 让用户能够以结构化格式导出完整体检结果、表格指标和空间图层，并确保不同格式引用同一份报告和相同分析参数。

**阻塞于：** 04：按设施类别识别服务盲区；08：生成有依据的规划建议

Status: ready-for-human

- [ ] JSON 导出包含完整报告契约、数据质量信息和规划建议。
- [ ] CSV 导出包含民生设施明细、类别评分和汇总指标，并使用清晰的中文列名。
- [ ] GeoJSON 导出包含等时圈、类别级服务区域和规划候选位置。
- [ ] 所有导出包含或引用统一的报告标识、生成时间、分析参数和 BD-09 坐标系说明。
- [ ] 用户可以在报告界面选择所需导出格式，并获得清晰的成功或失败反馈。
- [ ] 导出文件名包含可识别的分析地点、生成日期或报告标识。
- [ ] 自动化测试使用同一标准报告验证三种格式的数据一致性和必要字段。
